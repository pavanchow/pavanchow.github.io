1 Propositions & Truth Values

A proposition is a statement that is either true or false—never both, never neither. This binary nature is fundamental to how computers think.

✓ Valid Propositions

"The sky is blue" → True "5 > 10" → False "Paris is in France" → True "2 + 2 = 5" → False "This model is trained" → True/False

✗ Not Propositions

"Hello!" → Greeting, not T/F "What time is it?" → Question, not T/F "x + 5" → Expression, not T/F "Maybe" → Not definite T/F "Do your homework" → Command, not T/F

Truth Values

Every proposition has exactly one of two truth values:

  • True (T) — often represented as 1
  • False (F) — often represented as 0

💡 Binary Thinking

Computers are built on binary: everything is 0 or 1, off or on, false or true. This isn't a limitation—it's incredibly powerful. Complex decisions are built by combining many simple true/false questions.

🤖 In AI

Classification models answer propositions: "Is this email spam?" (T/F), "Is this a cat?" (T/F). Even when models output probabilities (0.73), we often threshold them to get a final true/false decision.

2 AND / OR / NOT

These three operations let you combine and modify propositions to build complex conditions from simple ones.

NOT (Negation) — ¬ or !

NOT flips the truth value. If something is true, NOT makes it false, and vice versa. 

        NOT reverses the truth value:
        
        NOT True  = False
        NOT False = True
        
        Example:
        "The light is on" is True
        "The light is NOT on" is False

📝 NOT in Code

Python: not True → False not False → True not (5 > 3) → False Math: ¬T = F ¬F = T

AND (Conjunction) — ∧ or &&

AND is true only when both parts are true. Think of it as requiring two conditions to pass. 

        AND requires BOTH to be true:
        
        True  AND True  = True   ✓ (both pass)
        True  AND False = False  ✗ (one fails)
        False AND True  = False  ✗ (one fails)
        False AND False = False  ✗ (both fail)
        
        Example:
        "I have money" AND "Store is open" → Can I shop?
        Both must be true to shop!

📝 AND in Code

Python: True and True → True True and False → False (5 > 3) and (2 < 4) → True Real example: if age >= 18 and has_id: allow_entry()

OR (Disjunction) — ∨ or ||

OR is true when at least one part is true. Think of it as needing only one condition to pass. 

        OR requires AT LEAST ONE to be true:
        
        True  OR True  = True   ✓ (at least one)
        True  OR False = True   ✓ (at least one)
        False OR True  = True   ✓ (at least one)
        False OR False = False  ✗ (neither passes)
        
        Example:
        "It's weekend" OR "It's holiday" → Can I sleep in?
        Either one being true is enough!

📝 OR in Code

Python: True or False → True False or False → False (5 > 10) or (2 < 4) → True Real example: if is_admin or is_moderator: show_controls()

💡 Remember the Pattern

AND is strict: all must be true → "Both/All"
OR is lenient: any can be true → "At least one"
NOT is a flip: opposite truth value

3 If-Then Reasoning

If-then statements (implications) are the backbone of logical reasoning and programming. "If A is true, then B follows."

Structure

        IF [condition] THEN [result]
        
        "If it rains, then the ground gets wet"
        
        Condition (antecedent): "it rains"
        Result (consequent): "the ground gets wet"
        
        Written as: P → Q (P implies Q)

When is If-Then True?

An implication P → Q is only false when the condition (P) is true but the result (Q) is false. This is a broken promise.

P (If) Q (Then) P → Q Interpretation
T T T Promise kept ✓
T F F Promise broken ✗
F T T No promise made
F F T No promise made

📝 Real Example

"If you pass the test, you get a certificate" Pass? Certificate? Promise kept? Yes Yes ✓ True (got what was promised) Yes No ✗ False (promise broken!) No Yes ✓ True (bonus! no promise broken) No No ✓ True (no promise was made)

🤖 If-Then in AI

Decision trees are chains of if-then rules. "If pixel brightness > 128, then go right, else go left." Neural network activation: "If weighted sum > threshold, then fire." Even attention mechanisms use if-then logic: "If these tokens are related, then attend more."

4 Truth Tables

A truth table systematically shows all possible input combinations and their outputs. It's the complete specification of a logical operation.

Building a Truth Table

  1. List all variables (P, Q, etc.)
  2. Write all possible combinations of T/F
  3. Compute the result for each combination
        For n variables, you need 2ⁿ rows:
        
        1 variable (P):      2¹ = 2 rows   (T, F)
        2 variables (P, Q):  2² = 4 rows   (TT, TF, FT, FF)
        3 variables:         2³ = 8 rows
        4 variables:         2⁴ = 16 rows

🤖 Logic Gates in Neural Networks

A single perceptron can learn AND and OR, but NOT XOR! This was the famous limitation discovered in 1969. It's why we need multiple layers (deep learning)—to combine simple logic gates into complex decision boundaries.

🎯 Key Takeaways

  • Propositions are statements that are either True or False
  • NOT flips truth values; AND requires all true; OR requires at least one
  • If-then is only false when the condition is true but the result is false
  • Truth tables exhaustively show all input/output combinations
  • Logic is the foundation of programming conditions and AI decision-making
